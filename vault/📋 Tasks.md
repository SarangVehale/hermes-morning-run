# How to use this file

Plain markdown task list. Edit on any device — the morning run reads from here for the Brief's Tasks section.

Sections by priority:

- `## Today` — items the Brief surfaces in today's task list
- `## This week` — backlog
- `## Eventually` — someday/maybe

Tag with `#today` or `#urgent` for the Brief skill's heuristics. Standard markdown checkboxes `- [ ]` for open, `- [x]` for done.

When you finish a task, check it off. The morning run does not auto-clear completed tasks — review and clean this file manually whenever it gets long.
